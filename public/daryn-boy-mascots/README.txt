Для сайта Next.js скопируйте PNG из архива в:
public/mascots/

Пример пути на сайте: /mascots/01_hero.png
Для GitHub Pages используйте basePath /daryn-kids, как в настройках проекта.

Движение на сайте можно реализовать через лёгкую CSS-анимацию (float, wave).
